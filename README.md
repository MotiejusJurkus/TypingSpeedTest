
# 🧠 SpeedTyper

SpeedTyper is a fast, interactive typing game built with HTML, CSS, and JavaScript. It measures your typing speed, accuracy, and displays real-time statistics and charts. Ideal for improving typing skills with engaging UI elements and themes.

## How to Run

1. **Clone or download** this repository.
2. Using Live Server (VS Code extension):
 - Open the TypingSpeedTest folder in VS Code
 - Right-click index.html → Open with Live Server
3. Start typing and track your progress in real-time!


## Features

-  Typing speed test with real-time feedback (You can use ESC to reset and ENTER to restart the test with new text)
-  Dynamic charts displaying words per minute (WPM) and accuracy
-  Dark mode toggle
-  Selectable Countdown timer for each round (Click the timer!)
-  Randomized text challenges
-  Organized asset and modular CSS/JS structure
